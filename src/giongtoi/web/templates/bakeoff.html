So sánh mô hình (nghe mù)

Cùng một mẫu giọng của bạn được đưa cho từng mô hình đọc 8 câu thử. File được đặt tên ngẫu nhiên A/B/C. Bạn nghe, chấm điểm 1–5, rồi mới bấm “Hiện tên mô hình”.

Tạo một lượt so sánh mới (cần có ít nhất một mẫu giọng):

./scripts/bakeoff.sh{% if voices %} --voice {{ voices[0].id }}{% endif %}

Muốn thêm F5-TTS vào so sánh: chạy ./scripts/setup.sh --with-f5 trước (tải PyTorch, ~1–2 GB).
