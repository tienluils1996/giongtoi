# GiọngTôi 🎙️

Clone giọng nói của chính bạn và đọc văn bản tiếng Việt bằng giọng đó. Chạy **100% offline trên Mac** (Apple Silicon).

- **Clone tức thì**: chỉ cần một mẫu giọng 5–10 giây, không cần huấn luyện.
- **Văn bản dài**: chia chương theo `#` hoặc 2 dòng trống. Tự tách câu, chạy nền, tạm dừng/tiếp tục được, và tạo lại riêng từng câu đọc sai.
- **Chuẩn hoá tiếng Việt**: tự đổi số, ngày, giờ, tiền, %, đơn vị, số điện thoại, viết tắt (TP.HCM, UBND…) thành chữ, và Việt hoá từ tiếng Anh (Facebook → phây búc).
- **Từ điển phát âm** do bạn tự thêm.
- **Chỉnh tốc độ** và khoảng nghỉ giữa câu, giữa đoạn.
- **Xuất WAV + MP3**, có gắn metadata `AI-generated by GiọngTôi`, có lịch sử.
- **So sánh mô hình bằng nghe mù** (VieNeu-TTS và F5-TTS).

## Cài đặt

Không cần Homebrew. Script tự cài [uv](https://docs.astral.sh/uv/), Python 3.11 và các thư viện cần thiết.

```bash
./scripts/setup.sh              # engine mặc định VieNeu-TTS (nhẹ, không cần PyTorch)
./scripts/setup.sh --with-f5    # thêm F5-TTS để so sánh (cần PyTorch, ~2 GB)
./scripts/build_app.sh          # (tuỳ chọn) tạo ~/Applications/GiọngTôi.app
```

Lần chạy đầu tiên sẽ tải mô hình về (VieNeu ~1 GB, F5 ~1,5 GB). Từ đó trở đi chạy hoàn toàn offline.

## Sử dụng

```bash
./scripts/run.sh                # mở web UI trong trình duyệt (http://127.0.0.1:7861)
./scripts/run.sh app            # mở dạng cửa sổ ứng dụng
./scripts/run.sh say "Xin chào" # đọc nhanh một câu ra file WAV/MP3
```

1. **Giọng của tôi**: tạo hồ sơ giọng, rồi ghi âm theo câu mẫu (hoặc tải file lên). Một mẫu là đủ để dùng; ghi khoảng 5–20 câu để có nhiều mẫu mà chọn.
2. **Đọc văn bản**: dán văn bản (hoặc tải `.txt`/`.md`), chọn giọng và tốc độ, rồi bấm **Tạo giọng đọc**.
3. Ở trang kết quả: nghe từng câu. Câu nào đọc sai thì sửa chữ ngay tại chỗ (ví dụ viết lại theo cách đọc), bấm **Đọc lại**. Chương sẽ tự ghép lại.
4. **Từ điển**: thêm từ hay bị đọc sai, ví dụ `Netflix → nét phlích`.

### Mẹo ghi âm
- Phòng yên tĩnh, có nhiều đồ mềm (rèm, chăn). Dùng mic rời hoặc mic MacBook. **Không dùng AirPods**: mic Bluetooth bị nén nên giọng clone sẽ giống giọng gọi điện.
- Đọc tự nhiên, đúng tốc độ bạn muốn giọng clone đọc. Mẫu tốt nhất dài 5–12 giây.
- Nếu cửa sổ app không xin được quyền micro, mở `http://127.0.0.1:7861` bằng Safari hoặc Chrome để ghi âm.

## So sánh mô hình (nghe mù)

```bash
./scripts/bakeoff.sh --voice giong-cua-toi
```

Lệnh này đưa cùng một mẫu giọng của bạn cho mỗi mô hình đọc 8 câu thử, đặt tên file ngẫu nhiên A/B, rồi mở trang chấm điểm. Chấm xong bấm **Hiện tên mô hình**. Sau đó chọn mô hình thắng ở ô *Mô hình* trên trang Đọc văn bản (app nhớ lựa chọn cuối cùng).

| Mô hình | Ưu điểm | Lưu ý |
|---|---|---|
| **VieNeu-TTS v3 Turbo** (mặc định) | 48 kHz, chạy ONNX trên CPU, nhanh (~5× thời gian thực trên M4), đọc trộn Việt–Anh tốt, giấy phép Apache-2.0 | Mẫu tham chiếu chỉ dùng tối đa ~8 giây |
| **F5-TTS Vietnamese** | Bắt chước ngữ điệu và cảm xúc của mẫu tốt | Cần transcript đúng của mẫu, chậm hơn, giấy phép CC-BY-NC-SA (chỉ dùng cá nhân) |

## Dữ liệu nằm ở đâu

Code nằm trong thư mục này (OneDrive được). Mọi thứ nặng hoặc riêng tư nằm ở `~/VoiceCloneData` (đổi được qua biến `GIONGTOI_DATA_DIR`):

```
~/VoiceCloneData/
  .venv/              môi trường Python
  models/             mô hình đã tải (HF_HOME)
  voices/<id>/raw     bản ghi gốc
  voices/<id>/refs    mẫu đã xử lý (khử ồn, cắt lặng, chuẩn hoá âm lượng)
  projects/<id>/      audio từng câu + file chương WAV/MP3
  bakeoff/            các lượt nghe mù
  giongtoi.sqlite3    hồ sơ, dự án, từ điển, cài đặt
```

**Backup giọng của bạn:** sao chép thư mục `~/VoiceCloneData/voices/`. Dữ liệu giọng không bao giờ được đưa vào git.

## Phát triển

```bash
./scripts/test.sh               # chạy toàn bộ test (dùng engine giả lập, không cần mô hình)
```

```
src/giongtoi/
  text/normalize.py   chuẩn hoá tiếng Việt      text/segment.py  chia chương / tách câu
  text/lexicon.py     từ điển mặc định           engines/         VieNeu, F5, giả lập
  audio/processing.py xử lý & xuất audio         storage/db.py    SQLite
  studio.py           nghiệp vụ + worker nền     web/             FastAPI + HTML/JS thuần
  bakeoff.py          nghe mù                    desktop.py       cửa sổ pywebview
```

Muốn thêm mô hình mới: viết một lớp có `name`, `sample_rate`, `supports_speed` và `synthesize(text, ref, speed)` trong `engines/`, rồi đăng ký trong `engines/registry.py`.

Thiết kế chi tiết: [docs/DESIGN.md](docs/DESIGN.md).

## Lộ trình tiếp theo
- Fine-tune trên chính giọng bạn (LoRA cho VieNeu hoặc fine-tune F5) từ các bản ghi trong `voices/<id>/raw`.
- Phong cách đọc: chọn mẫu tham chiếu theo cảm xúc cho từng đoạn.
- Nhập `.docx` và `.pdf`.

## Sử dụng có trách nhiệm
Chỉ clone giọng của chính bạn, hoặc của người đã đồng ý rõ ràng. Audio xuất ra được gắn nhãn AI trong metadata. Khi chia sẻ, hãy nói rõ đó là giọng do AI tạo.
