# GiọngTôi — Thiết kế

Chốt qua buổi "grilling" ngày 2026-11-18.

## Mục tiêu
App TTS đọc văn bản bằng chính giọng người dùng. Tiếng Việt là chính, tiếng Anh phụ.
Chạy 100% offline trên Mac (M4, 16 GB). Một người dùng, một giọng — nhưng có cấu trúc
hồ sơ giọng để thêm giọng khác dễ dàng.

## Engine
- **VieNeu-TTS v3 Turbo** (`vieneu`, Apache-2.0): 48 kHz, ONNX không cần torch, clone tức thì
  từ clip 3–8 s, song ngữ Việt–Anh. Engine mặc định.
- **F5-TTS-Vietnamese-ViVoice** (`hynt/…`, CC-BY-NC-SA, chỉ dùng cá nhân): cần PyTorch,
  cài qua extra `f5`. Ứng viên bake-off.
- viXTTS: bỏ qua ở vòng đầu (giấy phép Coqui, phụ thuộc nặng).

## Kiến trúc
```
src/giongtoi/
  config.py          đường dẫn dữ liệu (GIONGTOI_DATA_DIR, mặc định ~/VoiceCloneData)
  text/normalize.py  chuẩn hoá tiếng Việt (số, ngày, giờ, %, tiền, viết tắt, đơn vị)
  text/lexicon.py    từ điển phát âm (mặc định + của người dùng)
  text/segment.py    chia chương → đoạn → câu (gộp câu ngắn, cắt câu dài)
  engines/           Engine (giao diện), vieneu, f5, fake (cho test), registry
  audio/             xử lý mẫu giọng, ghép câu + khoảng nghỉ, tốc độ, xuất WAV/MP3 + metadata
  storage/           SQLite: voices, voice_refs, projects, chapters, segments, lexicon
  jobs/worker.py     hàng đợi nền một luồng, tạm dừng/tiếp tục, tạo lại câu
  web/               FastAPI + Jinja2 + JS thuần
  desktop.py         cửa sổ pywebview
```
Một "dự án đọc" = văn bản → chương → câu. Văn bản ngắn là dự án một chương.
Lịch sử = danh sách dự án.
